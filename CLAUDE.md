# Working on this repo

- `tokens/tokens.json` is the source of truth. Regenerate `tokens.css` from it; never edit colours by hand in CSS.
- Follow `docs/04-rules.md` and `docs/06-accessibility.md` (WCAG 2.2 AA) for every change.
- Colour minimums per page: Mauveine 28%, Logwood 800 10%, accents 11%.
- Course grids use the colour cap card; course, teacher, partner pages and print use the Editorial card inside a Mauveine or Weld band.
- Record every accepted change in `docs/10-accepted-decisions.md`.
