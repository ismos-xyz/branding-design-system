# 03.2 Hacker mode

*Settled. The dark theme, in full. In tokens it is the `hacker` theme; set `data-theme="hacker"` on the root.*

The terminal side of ISMOS: IDEs, labs, GitHub, Discord, code screens, and dark mode on the platform and the app. Same eight colours, same energy: Ink is the ground between bands, Mauveine, Logwood 800, Madder and Weld blocks carry the page, white is the text, Weld is the cursor.

## Rules

- **White text, never ghost white.** Body text, code and headings are white `#FFFFFF`. Never an off-white or ghost-white tint on a dark colour: it reads grey on cheap screens and is hard to read.
- **Ground.** Ink is the canvas. Logwood cards on Ink take a 1 px Logwood 700 edge; Logwood against Ink alone is 1.32:1.
- **Colour blocks.** Mauveine, Logwood 800, Madder, Weld and Indigo bands run full bleed between Ink bands, with the type from 03 (*What goes on each block*). Never two neighbouring bands in the same colour.
- **Two elevation surfaces.** For panels, menus and dialogs: Ink and Logwood only; levels are told apart by edges and the scrim. Colour blocks and filled cards are not elevation levels.
- **Weld.** Prompt, cursor, selection, rewards. Weld text on Ink is allowed (14.54:1). Ink type on Weld fills. 8% of a page.
- **Madder.** An accent only: bands and filled cards with Ink type. Never an alert.
- **Cochineal 300.** Errors and alerts. Always the three cues: Cochineal 300, the Alert icon, the word in capitals. AAA on Ink (9.35:1) and on Logwood (7.11:1).
- **Mauveine.** Filled blocks and buttons only, with white type (8.76:1). Never as text or lines on Ink (2.40:1): links use Mauveine 200, underlined.
- **Type.** IBM Plex Mono for code, commands and data. IBM Plex Sans for prose. Same scale and weights as light mode.
- **No glow, no coloured shadow, no accent border to "separate" a card.**

## Elevation in Hacker mode

| Level | Use | Hacker mode |
|---|---|---|
| 0 · flat | Page | Ink |
| 1 · raised | Cards, inputs, tables | Logwood + 1 px Logwood 700 edge |
| 2 · overlay | Menus, popovers, toasts, tooltips | Logwood + 1 px Logwood 400 edge |
| 3 · modal | Dialogs, drawers, sheets | Logwood + **2 px** Logwood 400 edge + `shadow-modal` + scrim, always on |

Level 3 differs from level 2 by the heavier edge and the scrim, without a third surface.

## Components in Hacker mode

- **Buttons:** primary Mauveine with white type; secondary 2 px white outline, white type.
- **Inputs:** Ink inside, 1.5 px Logwood 400 border (6.63:1 on Logwood), white text; focus Weld ring.
- **Checkbox and radio:** white borders; checked fill Mauveine 200 with Ink check.
- **Course card:** Logwood with a 1 px Logwood 700 edge; title and sentence in white; tags in Logwood 200; bar Mauveine 300. Or a colour fill (Mauveine, Logwood 800, Madder, Weld), as in light mode.
- **Icons:** white, 1.5 px.

## When to use it

Follow the device setting by default. Settings offers *Light · Hacker mode · Same as this device*. Every surface that ships is checked in both themes.
