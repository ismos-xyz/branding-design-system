# Button

The action a student takes: a verb and its object, sentence case, four words at most.

- **Primary** `.ism-btn`: `action` fill with `on-action` type: Mauveine with white type in both modes (8.76:1).
- **On a colour block** `.ism-btn--on-color`: Weld with Ink type (14.54:1) on Mauveine, Indigo and Logwood 800. On Madder use `.ism-btn--ink` (Ink, white type); on Weld the default Mauveine button.
- **Secondary** `.ism-btn--secondary`: transparent with a 2 px `text` outline.
- **Provide:** the label (sized against the Spanish string), and an optional 20 px line icon as `<img>` before it.
- `radius-4`, minimum height `tap-target` (44 px). Focus: 2 px `focus` outline.
- One primary per view; one per email, with the URL also written out.
- **Don't:** *Submit*, *OK*, *Let's go!*, round or pill buttons, shadows.
