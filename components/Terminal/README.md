# Terminal

The Hacker mode code surface: IDEs, labs, code screens.

- Ground `ink` (#000000) with a 1 px `logwood-700` edge: the darkest ground, for the most contrast. Output in white, `paper` (Plex Mono). Never off-white.
- Prompt and cursor in `weld`. Comments in `logwood-200`. Alerts in `cochineal-300` with the Alert icon and the word. Links in `mauveine-200`, underlined.
- **Provide:** the lines; wrap the prompt in `.pr`, comments in `.cm`, alerts in `.al`, cursor in `.cur`.
- The cursor blinks for 5 s at most, then stays solid (WCAG 2.2.2). With Reduce Motion on it never blinks.
